## Contract

The opt-in continuous producer delegates explicit original v3-next-open
`native_event_strategy` and `orders` configurations to `event_producer.py`.
It requires the genuine original WFO scorer, explicit Python/Rust selection,
source/binary/configuration pins and the actual returned backend, clock, fee,
funding, constraints and lifecycle metadata. No account execution/replay is
implemented by the sidecar; original public engines remain the authority.

Callback qualification is bounded to the original single-pass Python loop,
fast/audit runtime without shadow accounting/replay. Command timestamps remain
effective-bar timestamps; callback signals remain bar-close/next-open. Unknown
clocks, backend fallback or mismatched source/economics fail explicitly. Terminal
orders/positions follow the original mark-only policy, not hidden flattening.

Continuous observations now retain original finite one- or two-dimensional
financial streams. Multi-column margin is not flattened or rebuilt from equity;
all rows must align with the account clock. Shared byte-backed snapshot storage
preserves copy/pickle immutability. Original legacy scalar paths, defaults,
metric formulas and annual attribution gates remain unchanged. This is not a
new multi-symbol scientific qualification.
