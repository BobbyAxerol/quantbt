## Researcher Workflow

1. Supply the original verified diagnostics/Dossier and catalog. A Mode 4
   archive is optional; its absence does not prevent an explicit supported
   Mode 5 recipe. Attach the original shared report by its exact catalog ref.
2. Review source-bound findings: values, units, support, uncertainty, masks,
   competing explanations, configuration implications and bounded next action.
   The five-axis measures and six-matrix coverage retain their original owners.
3. Supply complete explicit recipe options. Review search feedback, eligibility
   and final selection separately. Record researcher choice or revision; a
   changed reason/choice produces a new immutable worksheet and plan seal.
4. Compile/export the private run pack. Supply original external data,
   strategy, ranges, financial endpoint/configuration, evidence and access.
   Preflight checks these inputs; it neither invokes the alpha nor asks trials.
5. Explicitly call the existing endpoint's `backtest`, then reconcile actual
   metadata and original final marks to the pack. Read the five linked views
   in JSON or Markdown. A configuration-only snapshot remains `NOT_RUN`.

The five ordered views are **Decision Summary**, **Alpha Behavior**, **Recipe
Comparison**, **Run Configuration**, and **Post-Run Qualification**. Matrix
and source references retain drill-down without embedding market/account
arrays in each recipe. Public defaults redact private prose/configuration.

guards on its actual second `data` argument before search, not just at prepare.
