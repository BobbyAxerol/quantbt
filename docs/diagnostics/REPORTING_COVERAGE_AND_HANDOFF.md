## Field Ownership And Limits

| Requested Output | Authoritative Owner | Unavailable / Interpretation Policy |
|---|---|---|
| Attempts, unique/effective points, failures, timing | Original ordered trial ledger, sampler telemetry and pre-search observations | No attempt count or duration inferred from candidate count; attempts are not independent origins |
| Geometry, factors/environments, sensitivity/local fragility | Shared diagnostics, existing Dossier/Matrix/probe owners and witnesses | Missing design/probe/state evidence stays named; adaptive TPE points are not a neutral whole-space design |
| R/Q/IS and fold consistency | Original raw metric observations, canonical effect reducer and exact masks | Positive R need not mean positive Q; own-mask means are not a matched decomposition |
| Native/proposed/applied dictionary, support, clocks, guard | Original task/decision/model sidecars | Shadow is not applied; missing/fallback/same-anchor folds remain in the policy view |
| Prediction/control loss | Qualified selected and acquired-row labels | Zero-Y/structural controls are error references, not executed policies; no full-pool oracle from a small label panel |
| Return, activity, DD, costs, fills/actions/campaigns | Original typed metric supplements / actual account reports | Each unit retains its meaning; no conversion from Sharpe or position regime counts |
| Final continuous performance | Exact original qualified continuous result with declared calendar | Wider flat pre/post periods disclosed; mean reset-fold metrics cannot fill this field |
| Intervals | Original registered mask/policy/source | No new bootstrap or favorable-only subset; unsupported intervals stay nonnumeric |
| Mode 5 winner, runner-up, floor/tail/components/mandate | Existing `DecisionReport` runtime snapshot | Fixed full-development calibration is not causal WFO or independent OOS; no outcome-driven reranking |
| Researcher recommendation / override | Explicit source-bound advice and `with_choice(..., reason=...)` | Compatibility is not superiority; choice records rationale but does not activate settings |

Optional absent campaign/fill/factor/probe fields are evidence limitations,
not missing software silently estimated from equity. Optional R06 winner-probe
accounts remain DEFERRED_APPROVED: they were not run under reporting approval.
No new gate, estimator, Ridge/model, regime fit or optimizer recipe was added.
Sampler fit/bull concentration has competing data/exposure/objective/selector
explanations; the report does not blame legacy TPE without a matched comparison.

## M5-12 Entry And Rollback

The approved reporting subphases are source-qualified, with original economic
positive/negative/insufficient findings preserved and no scientific policy
replacement. M5-12 still requires owner review of this handoff; it is not
started automatically.

1. Freeze final tracked source and candidate core/native pair under the approved
   versioning policy. Existing local artifacts certify earlier bytes only.
2. Build exact wheel/sdist, verify all package members against that source,
   private alpha/evidence exclusion and unchanged/native-compatible capabilities.
3. Run isolated installed consumers for existing and new public paths/examples;
   verify import origins, defaults, raw accounting and source manifests.
4. Preserve scientific/runtime route boundaries and record installed results,
   regression/cost/cleanup receipts before requesting remote/release approval.

No installed claim follows from this source checkout. Remote CPython/Linux,
merge/tag/PyPI/public consumer proof remain separately approved final steps.
Rollback for users is to omit the new `research_report()` call and optional
`research=` pre-search argument; old calls/defaults remain unchanged. This does
not turn failed source witnesses into valid reports or require disabling meta.
